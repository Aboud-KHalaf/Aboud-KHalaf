## Engineering Principles

- **Simplicity first** — the simplest solution that fully meets the requirements.
- **Separation of concerns** — UI renders state, ViewModels coordinate, the data layer owns the data.
- **Readable over clever** — clear naming, small focused units, no premature abstraction.
- **Verified changes** — tests for business logic, small focused commits, review before merge.
